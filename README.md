## Job Interview Simulator
Have you ever had a job interview? Chances are, if you're looking up Ren'Py novels on GitHub, probably not. 
This project givesa you a chance to experience a job interview for your dream company - Obliterate Corp. Navigate complicated interview questions to secure a spot as a destruction intern!

**Note:** 
The main company, Obliterate Corp., is an exaggerated depiction of a modern-day defense company. This choice is solely a reference to online memes about the moral implications behind engineers choosing to work for defense companies. This game holds no perspective or sentiment toward real-life events or industries.

This project was made as part of HackClub Snowglobe's weekend visual novel challenge.
